# GARUDA Review 2 Working Prototype

## Features
Dashboard, Customer Management, Vehicle Management, Service History, Analytics, Retention Insights and Service Reminders.

## Technology
Python, Flask, SQLite, HTML5, CSS3, JavaScript and Chart.js.

## Run in VS Code
1. Open this folder.
2. Terminal: `python -m venv venv`
3. Windows: `venv\Scripts\activate`
4. `pip install -r requirements.txt`
5. `python app.py`
6. Open `http://127.0.0.1:5000`

The database `garuda.db` is created automatically with demo records.

The retention module is a rule-based prototype for Review 2 demonstration, not a claimed trained ML model.
